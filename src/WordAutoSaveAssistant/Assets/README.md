# 图标来源与构建

来源：用户于 2026-10-06 提供的 JPG（codex-clipboard-5a5b7c39-c2fc-4e02-b55b-39d32a61f11b.jpg）。原图未修改。

使用 imagegen 内置编辑处理外部背景，并清理生成后局部底色瑕疵。编辑要求：去除外部网格背景，输出真实透明背景；保留灰蓝色圆角底、白色 W、折角文档轮廓、时钟与环形箭头；不增加文字、标记或装饰。资产为最终处理 PNG，而非原图的逐像素抠图。

AppIcon.png 保留编辑结果的透明通道。AppIcon.ico 由 tools/Convert-AppIcon.ps1 进行格式转换，包含 16、20、24、32、48、64、128、256 像素的 32 位 PNG 帧。脚本不覆盖已有输出。

需要重新生成 ICO 时，请给转换脚本传入新的输出路径；确认后再替换项目资产。发布程序无需外置图片。
